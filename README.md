# Telegram FA↔EN Translator Bot

باتی که ویس فارسی‌ات رو به متن فارسی تمیز تبدیل می‌کنه و ترجمه‌ی انگلیسی‌اش رو
تحویلت می‌ده — تا بتونی راحت با هوش مصنوعی‌ها به انگلیسی صحبت کنی.

- 🎤 **ویس فارسی** → متن فارسی + ترجمه‌ی انگلیسی
- ✍️ **متن فارسی** → ترجمه‌ی انگلیسی
- ✍️ **متن انگلیسی** → ترجمه‌ی فارسی
- 🎬 **ویدیو** → نسخه‌ی تمیزشده با زیرنویس + ریلز عمودی آماده‌ی اینستاگرام
  ([بخش ادیت ریلز](#-ادیت-ریلز-اینستاگرام-instagram-reels-editor))

همه‌چیز رایگانه و هیچ کلید API لازم نیست. تشخیص گفتار روی خود سیستم شما اجرا می‌شه
(با Whisper) و ترجمه از Google Translate عمومی استفاده می‌کنه.

## نصب و اجرا روی ویندوز (ساده)

### قدم ۱: نصب Python

اگر Python نصب نیست، از [python.org/downloads/windows](https://www.python.org/downloads/windows/)
فایل **Windows installer (64-bit)** رو دانلود و نصب کنید. موقع نصب حتماً تیک
**«Add python.exe to PATH»** رو بزنید.

### قدم ۲: دانلود پروژه

اگر Git ندارید، این دستور رو در PowerShell اجرا کنید تا پروژه روی دسکتاپ دانلود و
باز بشه:

```powershell
cd $HOME\Desktop
Invoke-WebRequest -Uri "https://github.com/mohamanasri27-arch/telegram-bot/archive/refs/heads/claude/web-setup-66999f.zip" -OutFile "bot.zip"
Expand-Archive -Path "bot.zip" -DestinationPath "." -Force
```

پوشه‌ای به اسم `telegram-bot-claude-web-setup-66999f` روی دسکتاپ ساخته می‌شه.

### قدم ۳: راه‌اندازی

وارد اون پوشه بشید و روی **`setup.bat`** دابل‌کلیک کنید. این فایل خودش:

- محیط مجازی می‌سازه
- همه‌ی وابستگی‌ها رو نصب می‌کنه
- توکن بات رو ازتون می‌پرسه و ذخیره می‌کنه

توکن بات رو از [@BotFather](https://t.me/BotFather) در تلگرام بگیرید (دستور
`/newbot` رو بزنید).

### قدم ۴: اجرا

روی **`run.bat`** دابل‌کلیک کنید. وقتی پیام `Bot started` رو دیدید، بات آماده‌ست.
برید توی تلگرام سراغ بات خودتون و `/start` بزنید.

> پنجره‌ی مشکی رو باز نگه دارید — تا وقتی بازه بات فعاله. برای خاموش کردن بات،
> پنجره رو ببندید یا `Ctrl + C` بزنید.

## نکات مهم

**اولین اجرا طول می‌کشه.** بار اولی که بات رو اجرا می‌کنید، مدل تشخیص گفتار
(حدود ۳ گیگابایت) یک‌بار دانلود می‌شه. مدل موقع بالا اومدن بات لود می‌شه، پس تا
وقتی این خط رو ندیدید ویس نفرستید:

```
=== BOT IS READY - you can send messages now ===
```

اگر ترجیح می‌دید سریع‌تر شروع کنید و دقت کمی پایین‌تر باشه، بعد از بالا اومدن بات
دستور `/accuracy` رو بزنید تا به مدل سبک‌تر (۱.۶ گیگ) سوییچ کنه.

**اگر دانلود مدل گیر کرد،** ممکنه دسترسی به سرور مدل‌ها (huggingface.co) از ایران
محدود باشه. در این صورت فقط برای همون یک‌بار دانلود، VPN رو روشن کنید. بعد از
دانلود، دیگه نیازی به VPN نیست چون مدل روی سیستم شما ذخیره می‌شه.

**سرعت پردازش ویس** به CPU سیستم شما بستگی داره. یک ویس ۳۰ ثانیه‌ای معمولاً بین
۱۰ تا ۴۰ ثانیه طول می‌کشه.

## بالا بردن دقت ⭐

دقت روی دو فایل سوار است. تفاوت‌شان مهم است:

### `glossary.txt` — واژه‌نامه‌ی عمومی (بدون محدودیت)

حدود ۲۸۰ اصطلاح آماده در حوزه‌های هوش مصنوعی، برنامه‌نویسی، وب و دیتابیس،
کسب‌وکار و مالی، و مکاتبات اداری. هر خط به شکل `کلمه فارسی = English Term` است و
ترجمه را دقیقاً روی همان معادل قفل می‌کند.

این فایل فقط روی ترجمه اثر دارد، پس **هیچ محدودیت اندازه‌ای ندارد** — هر تعداد
اصطلاح خواستید اضافه کنید.

### `my_terms.txt` — واژه‌هایی که با `/add` یاد می‌دهید ⭐

راحت‌ترین و مؤثرترین راه. لازم نیست هیچ فایلی را باز کنید — کافی است در تلگرام
بنویسید `/add ...` و بات فوراً یاد می‌گیرد (بخش دستورات را ببینید).

### `vocabulary.txt` — قالب اصطلاحات شخصی (اختیاری)

اگر ترجیح می‌دهید چند اصطلاح را از قبل و دستی وارد کنید، این فایل جای آن است.
به‌صورت پیش‌فرض خالی است.

> ⚠️ **`my_terms.txt` و `vocabulary.txt` روی هم باید کوتاه بمانند (حدود ۳۰ خط).**
> این کلمات به مدل تشخیص گفتار داده می‌شوند و Whisper فقط ۲۲۳ توکن اول را
> می‌خواند و بقیه را بی‌صدا دور می‌ریزد. اگر بیش از حد شود، بات موقع اجرا هشدار
> می‌دهد و می‌گوید چند خط جا شده است. اصطلاحات اضافی را به `glossary.txt` منتقل
> کنید که هیچ محدودیتی ندارد.

`/add` بدون ری‌استارت اثر می‌کند. برای تغییر دستی فایل‌ها، بات را ببندید و دوباره
اجرا کنید.

### جمع فارسی

اگر بنویسید `پرونده = case file`، بات خودش «پرونده‌ها» را هم می‌شناسد و
`case files` ترجمه می‌کند. لازم نیست حالت جمع را جداگانه بنویسید.

## محدودیت طول ویس

حداکثر طول ویس **۳ دقیقه** است. ویس طولانی‌تر رد می‌شود و پیام می‌گیرید که آن را
به چند بخش کوتاه‌تر تقسیم کنید.

## اجرای دائمی (۲۴ ساعته)

- `run.bat` اگر بات به هر دلیلی کرش کند، خودش بعد از ۱۰ ثانیه دوباره اجرایش می‌کند.
- برای اینکه بات با هر بار روشن شدن ویندوز خودکار بالا بیاید، یک‌بار روی
  **`install-autostart.bat`** دابل‌کلیک کنید.

> توجه: بات فقط تا وقتی کار می‌کند که کامپیوتر روشن باشد. برای کارکرد واقعاً
> ۲۴ ساعته، به یک سیستم همیشه‌روشن (سرور) نیاز است.

## دستورات بات

| دستور | کار |
|---|---|
| `/start` | پیام خوش‌آمد |
| `/help` | راهنمای کامل |
| `/add فارسی = English` | یاد دادن واژه‌ی جدید به بات |
| `/terms` | نمایش واژه‌هایی که یاد داده‌اید |
| `/mode` | جابه‌جایی بین خروجی عادی و حالت پرامپت |
| `/accuracy` | جابه‌جایی بین مدل سریع و مدل دقیق |
| `/fillers` | حذف یا نگه داشتن کلمات پرکننده |
| `/settings` | نمایش وضعیت فعلی |

### یاد دادن واژه از داخل تلگرام ⭐

لازم نیست هیچ فایلی را دستی ویرایش کنید. هر جا بات کلمه‌ای را اشتباه شنید یا بد
ترجمه کرد، همان‌جا در تلگرام بنویسید:

```
/add ابر آروان = ArvanCloud
```

از آن لحظه به بعد هم آن کلمه را بهتر می‌شنود و هم دقیقاً همان معادل انگلیسی را در
ترجمه می‌گذارد — بدون نیاز به ری‌استارت.

این واژه‌ها در `my_terms.txt` ذخیره می‌شوند که **موقع به‌روزرسانی بات پاک
نمی‌شود**، پس چیزی که به بات یاد داده‌اید از دست نمی‌رود. اگر واژه‌ای را که
از قبل در `glossary.txt` هست دوباره تعریف کنید، تعریف شما برنده است.

### حالت پرامپت

با `/mode` روشن می‌شود. به‌جای یک ترجمه‌ی یک‌تکه، خروجی را این‌طور مرتب می‌کند:

```
## Context
I am a backend developer. We store user data in a PostgreSQL database.

## Task
Please write a script that migrates this data.
```

جمله‌های شما دست‌نخورده می‌مانند — فقط بین «توضیح زمینه» و «چیزی که می‌خواهید»
دسته‌بندی می‌شوند، چون مدل‌های هوش مصنوعی این ساختار را بهتر دنبال می‌کنند.

### حالت دقت حداکثری

با `/accuracy` بین دو مدل جابه‌جا می‌شوید:

| مدل | حجم | دقت فارسی | سرعت |
|---|---|---|---|
| `large-v3` | ۳ گیگ | عالی (پیش‌فرض) | کندتر |
| `large-v3-turbo` | ۱.۶ گیگ | خوب | حدود ۳ برابر سریع‌تر |

پیش‌فرض روی دقت تنظیم شده. `large-v3` هر ۳۲ لایه‌ی دیکودر را دارد، در حالی که
`turbo` فقط ۴ لایه دارد — و همین لایه‌ها هستند که صرف فعل فارسی («می‌کنم» در برابر
«کنم») را درست تشخیص می‌دهند.

انتخاب شما در `settings.json` ذخیره می‌شود و بعد از ری‌استارت هم می‌ماند. اگر
`WHISPER_MODEL` را در `.env` تعریف کرده باشید، آن بر تنظیمات اولویت دارد.

## 🎬 ادیت ریلز اینستاگرام (Instagram Reels Editor)

یک ویدیو را داخل پوشه می‌گذارید، و نسخه‌ی ویرایش‌شده‌اش در پوشه‌ی دیگری ظاهر
می‌شود. نه دکمه‌ای، نه تنظیمی برای هر ویدیو.

روی هر ویدیو این کارها انجام می‌شود:

| کار | توضیح |
| --- | --- |
| ✂️ حذف سکوت | مکث‌های طولانی وسط ویدیو بریده می‌شوند |
| 🔊 یکنواخت‌کردن صدا | صدای خیلی آهسته یا خیلی بلند به سطح استاندارد می‌رسد |
| 🎨 اصلاح رنگ | کنتراست و اشباع رنگ کمی بالا می‌رود (ملایم، نه افکت) |
| 📝 زیرنویس فارسی | گفتار به متن تبدیل و روی تصویر نوشته می‌شود |
| 🌍 ترجمه‌ی انگلیسی | فایل `.en.srt` جداگانه ساخته می‌شود |
| 📱 کلیپ عمودی | ویدیوهای بلند به چند کلیپ ۹:۱۶ برای ریلز و شورتز تقسیم می‌شوند |
| 🎵 موسیقی، لوگو، اینترو | اگر فایلشان را بگذارید، اضافه می‌شوند |

### قدم ۱: نصب ffmpeg (فقط یک بار)

ویرایش ویدیو بدون `ffmpeg` کار نمی‌کند. در PowerShell این خط را بزنید:

```powershell
winget install Gyan.FFmpeg
```

بعد از نصب، پنجره را **ببندید و دوباره باز کنید** تا ویندوز مسیر جدید را بشناسد.

### قدم ۲: اجرا

روی **`reels-editor.bat`** دابل‌کلیک کنید. سه پوشه خودش ساخته می‌شود:

```
videos-in/     ← ویدیوها را اینجا بگذارید
videos-out/    ← نتیجه اینجا ظاهر می‌شود
assets/        ← موسیقی، لوگو، اینترو و اوترو (اختیاری)
```

### قدم ۳: ویدیو بگذارید

فایل را داخل `videos-in` کپی کنید و منتظر بمانید. برنامه صبر می‌کند تا کپی
کامل شود، بعد شروع می‌کند — پس ویدیوی نیمه‌کپی‌شده هیچ‌وقت ویرایش نمی‌شود.

برای ویدیویی به اسم `film.mp4` این‌ها ساخته می‌شود:

```
videos-out/film/
    film-edited.mp4            ← ویدیوی نهایی
    film-clips/clip-01.mp4     ← کلیپ‌های کوتاه عمودی
    film-clips/clips.txt       ← هر کلیپ از کدام دقیقه برداشته شده
    film.fa.srt                ← زیرنویس فارسی
    film.en.srt                ← زیرنویس انگلیسی
    film.transcript.txt        ← متن کامل حرف‌ها
    film-cover.jpg             ← عکس کاور
```

فایل اصلی به `videos-in/done/` منتقل می‌شود تا دوباره ویرایش نشود.

> برای ویرایش یک فایل مشخص بدون پوشه‌ها:
> `python watch_videos.py C:\Users\me\Desktop\film.mp4`

### برندینگ (اختیاری)

این فایل‌ها را در پوشه‌ی `assets` بگذارید و اسمشان را در `video_settings.json`
بنویسید:

- `intro.mp4` — ویدیوی کوتاه ابتدای کار
- `outro.mp4` — ویدیوی کوتاه پایانی
- `music.mp3` — موسیقی پس‌زمینه (وقتی حرف می‌زنید خودکار کم می‌شود)
- `logo.png` — لوگو در گوشه‌ی تصویر (با پس‌زمینه‌ی شفاف)

```json
{
  "branding": {
    "intro": "intro.mp4",
    "outro": "outro.mp4",
    "music": "music.mp3",
    "logo": "logo.png"
  }
}
```

هرکدام را نخواستید، اسمش را خالی (`""`) بگذارید.

### تنظیمات — `video_settings.json`

این فایل بار اول خودش ساخته می‌شه. **همه‌چیز اختیاریه** — پیش‌فرض‌ها ساده‌اند و
هر کدام را بخواهید برای یک ویدیوی خاص روشن می‌کنید.

#### پاکسازی

| کلید | پیش‌فرض | کارش |
| --- | --- | --- |
| `cleanup.remove_silence` | `true` | حذف مکث‌ها |
| `cleanup.silence_threshold_db` | `-34` | اگر حرف‌های آهسته بریده می‌شوند، به `-40` ببرید |
| `cleanup.min_silence_seconds` | `0.8` | مکث کوتاه‌تر از این دست نمی‌خورد |
| `cleanup.normalize_audio` | `true` | یکنواخت کردن صدا |

#### دقت زیرنویس ⭐

مهم‌ترین بخش. این‌ها فقط روی **متن** اثر دارند، نه روی صدای ویدیو.

| کلید | پیش‌فرض | کارش |
| --- | --- | --- |
| `accuracy.clean_audio_first` | `true` | صدا قبل از تشخیص تمیز می‌شود (نویز، همهمه، بم‌های اتاق) |
| `accuracy.topic` | `""` | **یک جمله درباره‌ی موضوع ویدیو** — بیشترین تأثیر را دارد |
| `accuracy.use_context` | `false` | جمله‌های قبلی را هم در نظر بگیرد؛ روی صدای تمیز بهتر، روی صدای شلوغ بدتر |

مثال برای `topic`:

```json
"accuracy": {
  "topic": "این ویدیو درباره‌ی برنامه‌نویسی، وایب کدینگ و ساخت وب‌سایت است."
}
```

> این یک خط، بیشتر از هر تنظیم دیگری دقت را بالا می‌برد. وقتی بداند موضوع
> چیست، دیگر کلمه‌های تخصصی را با کلمه‌های عادیِ هم‌آوا اشتباه نمی‌گیرد.

برای اسم‌های خاص و اصطلاحات، از واژه‌نامه استفاده کنید (`/add` در تلگرام یا
مستقیم در `my_terms.txt`) — همان واژه‌نامه‌ی بات، روی زیرنویس ویدیو هم اثر دارد.

#### زبان زیرنویس

| کلید | پیش‌فرض | کارش |
| --- | --- | --- |
| `language` | `"fa"` | زبانی که در ویدیو حرف زده می‌شود |
| `subtitles.burn` | `["fa"]` | چه زبان‌هایی روی تصویر نوشته شوند |
| `subtitles.translate_to` | `["en","de"]` | چه زبان‌هایی فایل `.srt` بسازند |

`burn` یک لیست مرتب است: اولی بزرگ‌تر و بالاتر، دومی کوچک‌تر و پایین‌تر.

```json
"subtitles": { "burn": ["fa"] }            // فقط فارسی
"subtitles": { "burn": ["fa", "en"] }      // فارسی بالا، انگلیسی پایین
"subtitles": { "burn": ["de"] }            // فقط آلمانی
"subtitles": { "burn": [] }                // هیچ‌چیز روی تصویر نوشته نشود
```

بیش از ۱۳۰ زبان پشتیبانی می‌شود: `en` انگلیسی، `de` آلمانی، `ar` عربی،
`tr` ترکی، `fr` فرانسه، `es` اسپانیایی و…

فونت هر زبان جداست:

```json
"subtitles": {
  "fonts": { "fa": "Vazirmatn", "de": "Arial", "default": "Arial" }
}
```

#### انیمیشن زیرنویس

| مقدار | چه شکلی است |
| --- | --- |
| `"none"` | بدون انیمیشن، یک‌دفعه ظاهر می‌شود |
| `"fade"` | محو نرم ورود و خروج — **پیش‌فرض** |
| `"rise"` | همراه با محو، کمی از پایین بالا می‌آید |
| `"pop"` | همراه با محو، کمی بزرگ می‌شود |
| `"karaoke"` | هر کلمه دقیقاً وقتی گفته می‌شود روشن می‌شود |

همه‌شان **تک‌رنگ** هستند — نه رنگین‌کمان، نه چشمک. `karaoke` همان سبکی است که در
ریلزهای حرفه‌ای می‌بینید، ولی با خاکستری و سفید به‌جای رنگ‌های تند.

```json
"subtitles": { "animation": "karaoke", "animation_ms": 180 }
```

#### ظاهر زیرنویس

| کلید | پیش‌فرض | کارش |
| --- | --- | --- |
| `subtitles.font_size_pct` | `5.2` | اندازه‌ی زبان اصلی |
| `subtitles.secondary_font_size_pct` | `3.2` | اندازه‌ی زبان دوم |
| `subtitles.outline_width` | `3.0` | ضخامت حاشیه‌ی مشکی |
| `subtitles.bold` | `true` | ضخیم بودن حروف |
| `subtitles.margin_bottom_pct` | `7.0` | فاصله از پایین کادر |
| `subtitles.primary_color` | `"#FFFFFF"` | رنگ متن |
| `subtitles.dim_color` | `"#8C8C8C"` | رنگ کلمه‌ی هنوز گفته‌نشده (فقط در `karaoke`) |

#### صداگذاری (voiceover) 🎙️

صدای خودتان را ضبط کنید و روی ویدیو بگذارید.

| کلید | کارش |
| --- | --- |
| `voiceover.file` | فایل صدای ضبط‌شده (در پوشه‌ی `assets` یا مسیر کامل) |
| `voiceover.mode` | `"replace"` صدای اصلی حذف، `"mix"` صدای اصلی زیرش می‌ماند |
| `voiceover.original_volume` | در حالت `mix`، صدای اصلی چقدر بلند بماند |
| `voiceover.duck_original` | وقتی حرف می‌زنید، صدای اصلی پایین بیاید |
| `voiceover.start_at` | از ثانیه‌ی چندم ویدیو شروع شود |
| `voiceover.transcribe` | زیرنویس از روی صدای شما ساخته شود، نه صدای ویدیو |

```json
"voiceover": {
  "file": "narration.m4a",
  "mode": "replace",
  "start_at": 0
}
```

**نکته‌ی مهم:** وقتی صداگذاری فعال باشد، **حذف سکوت خودکار خاموش می‌شود** —
چون بریدن تصویر باعث می‌شود صدای ضبط‌شده از تصویر جلو بیفتد.

**زیرنویس از صدای شما ساخته می‌شود.** یعنی حتی روی یک ویدیوی بی‌صدا (مثلاً چند
پلان از یک محصول) اگر روش حرف بزنید، زیرنویس فارسی می‌گیرید.

#### تیزر تبلیغاتی 🎯

همه خاموش‌اند تا روشنشان کنید.

| کلید | کارش |
| --- | --- |
| `promo.hook_text` | جمله‌ای که روی ثانیه‌های اول می‌ماند (قلاب) |
| `promo.hook_seconds` | چند ثانیه بماند |
| `promo.hook_position` | `"top"` / `"middle"` / `"bottom"` |
| `promo.end_card_text` | کارت پایانی: آیدی، سایت، دعوت به اقدام |
| `promo.end_card_background` | رنگ پس‌زمینه‌ی کارت |
| `promo.punch_in` | زوم آرام روی ریلزها. `0` خاموش، `0.05` ملایم و حرفه‌ای |

```json
"promo": {
  "hook_text": "این ویدیو را تا آخر ببین",
  "end_card_text": "@my_page  |  لینک در بایو",
  "punch_in": 0.05
}
```

> متن فارسی کارت و قلاب با موتور زیرنویس نوشته می‌شود، نه با ابزار متن ffmpeg —
> برای همین حروف درست به هم می‌چسبند و راست‌به‌چپ درست درمی‌آید.

#### شکل خروجی

| کلید | مقادیر | کارش |
| --- | --- | --- |
| `output.format` | `source` / `vertical` / `square` / `landscape` | شکل ویدیوی اصلی |
| `output.framing` | `crop` / `blur` | وسط کادر را نگه دارد، یا کل کادر را با پس‌زمینه‌ی بلور |

`vertical` یعنی ۱۰۸۰×۱۹۲۰، `square` یعنی ۱۰۸۰×۱۰۸۰، `landscape` یعنی ۱۹۲۰×۱۰۸۰.

#### ریلزها

| کلید | پیش‌فرض | کارش |
| --- | --- | --- |
| `clips.count` | `5` | تعداد ریلزها |
| `clips.min_seconds` / `max_seconds` | `15` / `30` | طول هر ریلز |
| `clips.framing` | `"crop"` | `crop` وسط تصویر، `blur` کل تصویر |
| `clips.min_source_seconds` | `60` | ویدیوی کوتاه‌تر از این تکه‌تکه نمی‌شود |

### نکته‌های مهم

**اولین ویدیو کند است.** مدل تشخیص گفتار باید یک‌بار دانلود شود. اگر بات را قبلاً
اجرا کرده باشید، مدل از قبل هست و این مرحله رد می‌شود.

**زیرنویس فارسی خوانا.** فونت `Tahoma` روی همه‌ی ویندوزها هست و کار می‌کند، ولی
اگر [Vazirmatn](https://github.com/rastikerdar/vazirmatn) را نصب کنید و در
تنظیمات بنویسید `"fonts": {"fa": "Vazirmatn"}`، نتیجه به‌مراتب تمیزتر است.

**برای بالاترین دقت،** این سه کار را با هم بکنید: `accuracy.topic` را پر کنید،
اصطلاحات خاصتان را با `/add` به واژه‌نامه اضافه کنید، و مدل را روی `large-v3`
نگه دارید. هر سه رایگان‌اند و با هم بیشترین اثر را دارند.

**کلیپ‌ها از روی متن انتخاب می‌شوند.** برنامه دنبال بخش‌هایی می‌گردد که در آن‌ها
پیوسته حرف می‌زنید و جمله وسطش قطع نمی‌شود. این یک قاعده است، نه سلیقه — پس
گاهی لازم است `clips.count` را بالا ببرید و بین نتیجه‌ها خودتان انتخاب کنید.

**اگر تشخیص گفتار شکست بخورد** (مثلاً اینترنت قطع باشد و مدل دانلود نشده باشد)،
ویرایش متوقف نمی‌شود: ویدیو بدون زیرنویس ساخته می‌شود و دلیلش در پنجره لاگ می‌شود.

**کلمه‌ها را همان‌جا یاد بدهید.** واژه‌نامه‌ای که با `/add` در تلگرام می‌سازید،
روی زیرنویس ویدیوها هم اثر می‌گذارد — همان فایل و همان منطق.

## ساختار پروژه

- `bot.py` — نقطه ورود، هندلرها و دستورات تلگرام
- `transcriber.py` — تبدیل ویس فارسی به متن (محلی، با Whisper)
- `translator.py` — منطق ترجمه‌ی متن
- `persian_text.py` — اصلاح املای فارسی و حذف کلمات پرکننده
- `prompt_format.py` — ساختاردهی خروجی در حالت پرامپت
- `vocabulary.py` — بارگذاری فایل‌های واژگان
- `settings.py` — تنظیماتی که از تلگرام عوض می‌شوند
- `watch_videos.py` — دیدبان پوشه‌ی ویدیو و اجرای تک‌فایلی
- `video_pipeline.py` — ترتیب مرحله‌های ویرایش ویدیو
- `ffmpeg_tools.py` — دستورهای ffmpeg و ffprobe
- `subtitles.py` — ساخت فایل‌های زیرنویس ASS و SRT
- `clipper.py` — انتخاب و برش کلیپ‌های کوتاه عمودی
- `video_config.py` — تنظیمات ویرایش ویدیو
- `glossary.txt` — واژه‌نامه‌ی عمومی (قابل گسترش، بدون محدودیت)
- `vocabulary.txt` — اصطلاحات شخصی/شرکتی شما (کوتاه بماند)
- `my_terms.txt` — واژه‌های افزوده‌شده با `/add` (ساخته می‌شود، پاک نمی‌شود)
- `setup.bat` / `run.bat` — راه‌اندازی و اجرای ساده در ویندوز
- `reels-editor.bat` — اجرای «ادیت ریلز اینستاگرام» در ویندوز
- `requirements.txt` — وابستگی‌ها
- `.env.example` — نمونه‌ی متغیرهای محیطی

## مدیریت خطا

- تمام خطاها در پنجره‌ی اجرا لاگ می‌شن.
- در صورت بروز خطا، پیام فارسی قابل‌فهم به کاربر نمایش داده می‌شه.
- در صورت شکست موقت ترجمه، حداکثر ۳ بار با فاصله‌ی زمانی افزایشی تلاش مجدد می‌شه.

## محدودیت کیفیت ترجمه

ترجمه از Google Translate عمومی استفاده می‌کنه، که برای صحبت‌های روزمره درباره‌ی
کار خوب جواب می‌ده، ولی اصطلاحات خیلی تخصصی رو گاهی تحت‌اللفظی ترجمه می‌کنه. اگر
بعداً به کلید API یکی از مدل‌های زبانی (مثل Claude) دسترسی پیدا کردید،
`translator.py` رو می‌شه برای کیفیت به‌مراتب بالاتر به اون سوییچ کرد.
