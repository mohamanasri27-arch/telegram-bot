# Telegram FA↔EN Translator Bot

باتی که ویس فارسی‌ات رو به متن فارسی تمیز تبدیل می‌کنه و ترجمه‌ی انگلیسی‌اش رو
تحویلت می‌ده — تا بتونی راحت با هوش مصنوعی‌ها به انگلیسی صحبت کنی.

- 🎤 **ویس فارسی** → متن فارسی + ترجمه‌ی انگلیسی
- ✍️ **متن فارسی** → ترجمه‌ی انگلیسی
- ✍️ **متن انگلیسی** → ترجمه‌ی فارسی

همه‌چیز رایگانه و هیچ کلید API لازم نیست. تشخیص گفتار روی خود سیستم شما اجرا می‌شه
(با Whisper) و ترجمه از Google Translate عمومی استفاده می‌کنه.

## نصب و اجرا روی ویندوز (ساده)

### قدم ۱: نصب Python

اگر Python نصب نیست، از [python.org/downloads/windows](https://www.python.org/downloads/windows/)
فایل **Windows installer (64-bit)** رو دانلود و نصب کنید. موقع نصب حتماً تیک
**«Add python.exe to PATH»** رو بزنید.

### قدم ۲: دانلود پروژه

اگر Git ندارید، این دستور رو در PowerShell اجرا کنید تا پروژه روی دسکتاپ دانلود و
باز بشه:

```powershell
cd $HOME\Desktop
Invoke-WebRequest -Uri "https://github.com/mohamanasri27-arch/telegram-bot/archive/refs/heads/claude/web-setup-66999f.zip" -OutFile "bot.zip"
Expand-Archive -Path "bot.zip" -DestinationPath "." -Force
```

پوشه‌ای به اسم `telegram-bot-claude-web-setup-66999f` روی دسکتاپ ساخته می‌شه.

### قدم ۳: راه‌اندازی

وارد اون پوشه بشید و روی **`setup.bat`** دابل‌کلیک کنید. این فایل خودش:

- محیط مجازی می‌سازه
- همه‌ی وابستگی‌ها رو نصب می‌کنه
- توکن بات رو ازتون می‌پرسه و ذخیره می‌کنه

توکن بات رو از [@BotFather](https://t.me/BotFather) در تلگرام بگیرید (دستور
`/newbot` رو بزنید).

### قدم ۴: اجرا

روی **`run.bat`** دابل‌کلیک کنید. وقتی پیام `Bot started` رو دیدید، بات آماده‌ست.
برید توی تلگرام سراغ بات خودتون و `/start` بزنید.

> پنجره‌ی مشکی رو باز نگه دارید — تا وقتی بازه بات فعاله. برای خاموش کردن بات،
> پنجره رو ببندید یا `Ctrl + C` بزنید.

## نکات مهم

**اولین اجرا طول می‌کشه.** بار اولی که بات رو اجرا می‌کنید، مدل تشخیص گفتار
(حدود ۳ گیگابایت) یک‌بار دانلود می‌شه. مدل موقع بالا اومدن بات لود می‌شه، پس تا
وقتی این خط رو ندیدید ویس نفرستید:

```
=== BOT IS READY - you can send messages now ===
```

اگر ترجیح می‌دید سریع‌تر شروع کنید و دقت کمی پایین‌تر باشه، بعد از بالا اومدن بات
دستور `/accuracy` رو بزنید تا به مدل سبک‌تر (۱.۶ گیگ) سوییچ کنه.

**اگر دانلود مدل گیر کرد،** ممکنه دسترسی به سرور مدل‌ها (huggingface.co) از ایران
محدود باشه. در این صورت فقط برای همون یک‌بار دانلود، VPN رو روشن کنید. بعد از
دانلود، دیگه نیازی به VPN نیست چون مدل روی سیستم شما ذخیره می‌شه.

**سرعت پردازش ویس** به CPU سیستم شما بستگی داره. یک ویس ۳۰ ثانیه‌ای معمولاً بین
۱۰ تا ۴۰ ثانیه طول می‌کشه.

## بالا بردن دقت ⭐

دقت روی دو فایل سوار است. تفاوت‌شان مهم است:

### `glossary.txt` — واژه‌نامه‌ی عمومی (بدون محدودیت)

حدود ۲۸۰ اصطلاح آماده در حوزه‌های هوش مصنوعی، برنامه‌نویسی، وب و دیتابیس،
کسب‌وکار و مالی، و مکاتبات اداری. هر خط به شکل `کلمه فارسی = English Term` است و
ترجمه را دقیقاً روی همان معادل قفل می‌کند.

این فایل فقط روی ترجمه اثر دارد، پس **هیچ محدودیت اندازه‌ای ندارد** — هر تعداد
اصطلاح خواستید اضافه کنید.

### `my_terms.txt` — واژه‌هایی که با `/add` یاد می‌دهید ⭐

راحت‌ترین و مؤثرترین راه. لازم نیست هیچ فایلی را باز کنید — کافی است در تلگرام
بنویسید `/add ...` و بات فوراً یاد می‌گیرد (بخش دستورات را ببینید).

### `vocabulary.txt` — قالب اصطلاحات شخصی (اختیاری)

اگر ترجیح می‌دهید چند اصطلاح را از قبل و دستی وارد کنید، این فایل جای آن است.
به‌صورت پیش‌فرض خالی است.

> ⚠️ **`my_terms.txt` و `vocabulary.txt` روی هم باید کوتاه بمانند (حدود ۳۰ خط).**
> این کلمات به مدل تشخیص گفتار داده می‌شوند و Whisper فقط ۲۲۳ توکن اول را
> می‌خواند و بقیه را بی‌صدا دور می‌ریزد. اگر بیش از حد شود، بات موقع اجرا هشدار
> می‌دهد و می‌گوید چند خط جا شده است. اصطلاحات اضافی را به `glossary.txt` منتقل
> کنید که هیچ محدودیتی ندارد.

`/add` بدون ری‌استارت اثر می‌کند. برای تغییر دستی فایل‌ها، بات را ببندید و دوباره
اجرا کنید.

### جمع فارسی

اگر بنویسید `پرونده = case file`، بات خودش «پرونده‌ها» را هم می‌شناسد و
`case files` ترجمه می‌کند. لازم نیست حالت جمع را جداگانه بنویسید.

## محدودیت طول ویس

حداکثر طول ویس **۳ دقیقه** است. ویس طولانی‌تر رد می‌شود و پیام می‌گیرید که آن را
به چند بخش کوتاه‌تر تقسیم کنید.

## اجرای دائمی (۲۴ ساعته)

- `run.bat` اگر بات به هر دلیلی کرش کند، خودش بعد از ۱۰ ثانیه دوباره اجرایش می‌کند.
- برای اینکه بات با هر بار روشن شدن ویندوز خودکار بالا بیاید، یک‌بار روی
  **`install-autostart.bat`** دابل‌کلیک کنید.

> توجه: بات فقط تا وقتی کار می‌کند که کامپیوتر روشن باشد. برای کارکرد واقعاً
> ۲۴ ساعته، به یک سیستم همیشه‌روشن (سرور) نیاز است.

## دستورات بات

| دستور | کار |
|---|---|
| `/start` | پیام خوش‌آمد |
| `/help` | راهنمای کامل |
| `/add فارسی = English` | یاد دادن واژه‌ی جدید به بات |
| `/terms` | نمایش واژه‌هایی که یاد داده‌اید |
| `/mode` | جابه‌جایی بین خروجی عادی و حالت پرامپت |
| `/accuracy` | جابه‌جایی بین مدل سریع و مدل دقیق |
| `/fillers` | حذف یا نگه داشتن کلمات پرکننده |
| `/settings` | نمایش وضعیت فعلی |

### یاد دادن واژه از داخل تلگرام ⭐

لازم نیست هیچ فایلی را دستی ویرایش کنید. هر جا بات کلمه‌ای را اشتباه شنید یا بد
ترجمه کرد، همان‌جا در تلگرام بنویسید:

```
/add ابر آروان = ArvanCloud
```

از آن لحظه به بعد هم آن کلمه را بهتر می‌شنود و هم دقیقاً همان معادل انگلیسی را در
ترجمه می‌گذارد — بدون نیاز به ری‌استارت.

این واژه‌ها در `my_terms.txt` ذخیره می‌شوند که **موقع به‌روزرسانی بات پاک
نمی‌شود**، پس چیزی که به بات یاد داده‌اید از دست نمی‌رود. اگر واژه‌ای را که
از قبل در `glossary.txt` هست دوباره تعریف کنید، تعریف شما برنده است.

### حالت پرامپت

با `/mode` روشن می‌شود. به‌جای یک ترجمه‌ی یک‌تکه، خروجی را این‌طور مرتب می‌کند:

```
## Context
I am a backend developer. We store user data in a PostgreSQL database.

## Task
Please write a script that migrates this data.
```

جمله‌های شما دست‌نخورده می‌مانند — فقط بین «توضیح زمینه» و «چیزی که می‌خواهید»
دسته‌بندی می‌شوند، چون مدل‌های هوش مصنوعی این ساختار را بهتر دنبال می‌کنند.

### حالت دقت حداکثری

با `/accuracy` بین دو مدل جابه‌جا می‌شوید:

| مدل | حجم | دقت فارسی | سرعت |
|---|---|---|---|
| `large-v3` | ۳ گیگ | عالی (پیش‌فرض) | کندتر |
| `large-v3-turbo` | ۱.۶ گیگ | خوب | حدود ۳ برابر سریع‌تر |

پیش‌فرض روی دقت تنظیم شده. `large-v3` هر ۳۲ لایه‌ی دیکودر را دارد، در حالی که
`turbo` فقط ۴ لایه دارد — و همین لایه‌ها هستند که صرف فعل فارسی («می‌کنم» در برابر
«کنم») را درست تشخیص می‌دهند.

انتخاب شما در `settings.json` ذخیره می‌شود و بعد از ری‌استارت هم می‌ماند. اگر
`WHISPER_MODEL` را در `.env` تعریف کرده باشید، آن بر تنظیمات اولویت دارد.

## ساختار پروژه

- `bot.py` — نقطه ورود، هندلرها و دستورات تلگرام
- `transcriber.py` — تبدیل ویس فارسی به متن (محلی، با Whisper)
- `translator.py` — منطق ترجمه‌ی متن
- `persian_text.py` — اصلاح املای فارسی و حذف کلمات پرکننده
- `prompt_format.py` — ساختاردهی خروجی در حالت پرامپت
- `vocabulary.py` — بارگذاری فایل‌های واژگان
- `settings.py` — تنظیماتی که از تلگرام عوض می‌شوند
- `glossary.txt` — واژه‌نامه‌ی عمومی (قابل گسترش، بدون محدودیت)
- `vocabulary.txt` — اصطلاحات شخصی/شرکتی شما (کوتاه بماند)
- `my_terms.txt` — واژه‌های افزوده‌شده با `/add` (ساخته می‌شود، پاک نمی‌شود)
- `setup.bat` / `run.bat` — راه‌اندازی و اجرای ساده در ویندوز
- `requirements.txt` — وابستگی‌ها
- `.env.example` — نمونه‌ی متغیرهای محیطی

## مدیریت خطا

- تمام خطاها در پنجره‌ی اجرا لاگ می‌شن.
- در صورت بروز خطا، پیام فارسی قابل‌فهم به کاربر نمایش داده می‌شه.
- در صورت شکست موقت ترجمه، حداکثر ۳ بار با فاصله‌ی زمانی افزایشی تلاش مجدد می‌شه.

## محدودیت کیفیت ترجمه

ترجمه از Google Translate عمومی استفاده می‌کنه، که برای صحبت‌های روزمره درباره‌ی
کار خوب جواب می‌ده، ولی اصطلاحات خیلی تخصصی رو گاهی تحت‌اللفظی ترجمه می‌کنه. اگر
بعداً به کلید API یکی از مدل‌های زبانی (مثل Claude) دسترسی پیدا کردید،
`translator.py` رو می‌شه برای کیفیت به‌مراتب بالاتر به اون سوییچ کرد.
