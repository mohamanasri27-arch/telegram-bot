# Telegram FA↔EN Translator Bot

باتی که ویس فارسی‌ات رو به متن فارسی تمیز تبدیل می‌کنه و ترجمه‌ی انگلیسی‌اش رو
تحویلت می‌ده — تا بتونی راحت با هوش مصنوعی‌ها به انگلیسی صحبت کنی.

- 🎤 **ویس فارسی** → متن فارسی + ترجمه‌ی انگلیسی
- ✍️ **متن فارسی** → ترجمه‌ی انگلیسی
- ✍️ **متن انگلیسی** → ترجمه‌ی فارسی

همه‌چیز رایگانه و هیچ کلید API لازم نیست. تشخیص گفتار روی خود سیستم شما اجرا می‌شه
(با Whisper) و ترجمه از Google Translate عمومی استفاده می‌کنه.

## نصب و اجرا روی ویندوز (ساده)

### قدم ۱: نصب Python

اگر Python نصب نیست، از [python.org/downloads/windows](https://www.python.org/downloads/windows/)
فایل **Windows installer (64-bit)** رو دانلود و نصب کنید. موقع نصب حتماً تیک
**«Add python.exe to PATH»** رو بزنید.

### قدم ۲: دانلود پروژه

اگر Git ندارید، این دستور رو در PowerShell اجرا کنید تا پروژه روی دسکتاپ دانلود و
باز بشه:

```powershell
cd $HOME\Desktop
Invoke-WebRequest -Uri "https://github.com/mohamanasri27-arch/telegram-bot/archive/refs/heads/claude/web-setup-66999f.zip" -OutFile "bot.zip"
Expand-Archive -Path "bot.zip" -DestinationPath "." -Force
```

پوشه‌ای به اسم `telegram-bot-claude-web-setup-66999f` روی دسکتاپ ساخته می‌شه.

### قدم ۳: راه‌اندازی

وارد اون پوشه بشید و روی **`setup.bat`** دابل‌کلیک کنید. این فایل خودش:

- محیط مجازی می‌سازه
- همه‌ی وابستگی‌ها رو نصب می‌کنه
- توکن بات رو ازتون می‌پرسه و ذخیره می‌کنه

توکن بات رو از [@BotFather](https://t.me/BotFather) در تلگرام بگیرید (دستور
`/newbot` رو بزنید).

### قدم ۴: اجرا

روی **`run.bat`** دابل‌کلیک کنید. وقتی پیام `Bot started` رو دیدید، بات آماده‌ست.
برید توی تلگرام سراغ بات خودتون و `/start` بزنید.

> پنجره‌ی مشکی رو باز نگه دارید — تا وقتی بازه بات فعاله. برای خاموش کردن بات،
> پنجره رو ببندید یا `Ctrl + C` بزنید.

## نکات مهم

**اولین اجرا کمی طول می‌کشه.** بار اولی که بات رو اجرا می‌کنید، مدل تشخیص گفتار
(حدود ۱.۶ گیگابایت) یک‌بار دانلود می‌شه. مدل موقع بالا اومدن بات لود می‌شه، پس
وقتی پیام `Bot started` رو دیدید، ویس‌ها سریع پردازش می‌شن.

**اگر دانلود مدل گیر کرد،** ممکنه دسترسی به سرور مدل‌ها (huggingface.co) از ایران
محدود باشه. در این صورت فقط برای همون یک‌بار دانلود، VPN رو روشن کنید. بعد از
دانلود، دیگه نیازی به VPN نیست چون مدل روی سیستم شما ذخیره می‌شه.

**سرعت پردازش ویس** به CPU سیستم شما بستگی داره. یک ویس ۳۰ ثانیه‌ای معمولاً بین
۱۰ تا ۴۰ ثانیه طول می‌کشه.

## بالا بردن دقت با واژگان کاری خودتان ⭐

مهم‌ترین کاری که می‌توانید برای دقت بیشتر بکنید: فایل **`vocabulary.txt`** را باز
کنید و هر اصطلاح تخصصی، اسم شرکت، اسم سامانه یا کلمه‌ای که بات اشتباه تشخیص
می‌دهد را در یک خط جداگانه اضافه کنید.

مدل تشخیص گفتار روی این کلمات حساس‌تر می‌شود و دیگر آن‌ها را با کلمات شبیه اشتباه
نمی‌گیرد. بعد از هر تغییر، بات را ببندید و دوباره اجرا کنید.

## محدودیت طول ویس

حداکثر طول ویس **۳ دقیقه** است. ویس طولانی‌تر رد می‌شود و پیام می‌گیرید که آن را
به چند بخش کوتاه‌تر تقسیم کنید.

## اجرای دائمی (۲۴ ساعته)

- `run.bat` اگر بات به هر دلیلی کرش کند، خودش بعد از ۱۰ ثانیه دوباره اجرایش می‌کند.
- برای اینکه بات با هر بار روشن شدن ویندوز خودکار بالا بیاید، یک‌بار روی
  **`install-autostart.bat`** دابل‌کلیک کنید.

> توجه: بات فقط تا وقتی کار می‌کند که کامپیوتر روشن باشد. برای کارکرد واقعاً
> ۲۴ ساعته، به یک سیستم همیشه‌روشن (سرور) نیاز است.

## تنظیم دقت تشخیص گفتار

مدل پیش‌فرض `large-v3-turbo` هست که بهترین تعادل دقت و سرعت رو برای فارسی داره.
اگر خواستید عوضش کنید، فایل `.env` رو باز کنید و این خط رو اضافه کنید:

```
WHISPER_MODEL=large-v3
```

| مدل | حجم | دقت فارسی | سرعت |
|---|---|---|---|
| `small` | ۰.۵ گیگ | ضعیف | خیلی سریع |
| `medium` | ۱.۵ گیگ | متوسط | کند |
| `large-v3-turbo` | ۱.۶ گیگ | خیلی خوب | سریع (پیش‌فرض) |
| `large-v3` | ۳ گیگ | عالی | خیلی کند |

## ساختار پروژه

- `bot.py` — نقطه ورود و هندلرهای تلگرام
- `transcriber.py` — تبدیل ویس فارسی به متن (محلی، با Whisper)
- `translator.py` — منطق ترجمه‌ی متن
- `setup.bat` / `run.bat` — راه‌اندازی و اجرای ساده در ویندوز
- `requirements.txt` — وابستگی‌ها
- `.env.example` — نمونه‌ی متغیرهای محیطی

## مدیریت خطا

- تمام خطاها در پنجره‌ی اجرا لاگ می‌شن.
- در صورت بروز خطا، پیام فارسی قابل‌فهم به کاربر نمایش داده می‌شه.
- در صورت شکست موقت ترجمه، حداکثر ۳ بار با فاصله‌ی زمانی افزایشی تلاش مجدد می‌شه.

## محدودیت کیفیت ترجمه

ترجمه از Google Translate عمومی استفاده می‌کنه، که برای صحبت‌های روزمره درباره‌ی
کار خوب جواب می‌ده، ولی اصطلاحات خیلی تخصصی رو گاهی تحت‌اللفظی ترجمه می‌کنه. اگر
بعداً به کلید API یکی از مدل‌های زبانی (مثل Claude) دسترسی پیدا کردید،
`translator.py` رو می‌شه برای کیفیت به‌مراتب بالاتر به اون سوییچ کرد.
