# Telegram FA↔EN Technical Translator Bot

بات تلگرامی که پیام‌ها رو بین فارسی و انگلیسی ترجمه می‌کنه، مخصوص متن‌های فنی برنامه‌نویسی
و پرامپت‌هایی که برای مدل‌های هوش مصنوعی نوشته می‌شن. ترجمه با Claude API (مدل
`claude-sonnet-5`) انجام می‌شه و بلاک‌های کد، کد inline و اصطلاحات تکنیکال رایج
دست‌نخورده باقی می‌مونن.

## ساختار پروژه

- `bot.py` — نقطه ورود و هندلرهای تلگرام
- `translator.py` — منطق ترجمه با Claude API (مستقل از لایه‌ی تلگرام)
- `requirements.txt` — وابستگی‌ها
- `.env.example` — نمونه‌ی متغیرهای محیطی
- `.gitignore`

## پیش‌نیازها

- Python 3.10 یا بالاتر
- یک توکن بات تلگرام از [@BotFather](https://t.me/BotFather)
- یک کلید API از [Anthropic Console](https://console.anthropic.com/)

## نصب و اجرا روی ویندوز

۱. مخزن رو کلون کنید و وارد پوشه‌ی پروژه بشید (در PowerShell یا CMD):

```powershell
git clone <repository-url>
cd telegram-bot
```

۲. یک محیط مجازی بسازید و فعالش کنید:

```powershell
python -m venv venv
venv\Scripts\activate
```

۳. وابستگی‌ها رو نصب کنید:

```powershell
pip install -r requirements.txt
```

۴. فایل `.env.example` رو کپی کنید و به `.env` تغییر نام بدید:

```powershell
copy .env.example .env
```

۵. فایل `.env` رو با یک ویرایشگر متن باز کنید و مقادیر واقعی رو جایگزین کنید:

```
TELEGRAM_BOT_TOKEN=توکن_بات_تلگرام_شما
ANTHROPIC_API_KEY=کلید_API_آنتروپیک_شما
```

۶. بات رو اجرا کنید:

```powershell
python bot.py
```

اگر همه‌چیز درست باشه، پیام `Bot started` توی خروجی نمایش داده می‌شه و بات آماده‌ی
دریافت پیامه.

### توقف بات

برای متوقف کردن بات، در ترمینال کلیدهای `Ctrl + C` رو بزنید.

## دستورات بات

- `/start` — نمایش پیام خوش‌آمد و توضیح کوتاه نحوه‌ی استفاده
- `/help` — نمایش راهنمای کامل استفاده

## نحوه‌ی کار

- زبان پیام ورودی به‌صورت خودکار تشخیص داده می‌شه (فارسی یا انگلیسی).
- پیام فارسی به انگلیسی و پیام انگلیسی به فارسی ترجمه می‌شه.
- بلاک‌های کد (بین ` ``` `) و کد inline (بین `` ` ``) دقیقاً حفظ می‌شن.
- اسامی لایبراری‌ها، فریمورک‌ها، توابع و متغیرها ترجمه نمی‌شن.
- اصطلاحات تکنیکال رایج (API، endpoint، prompt، token و مشابه) در ترجمه‌ی فارسی به
  همون شکل انگلیسی باقی می‌مونن.
- حداکثر طول پیام پشتیبانی‌شده ۴۰۰۰ کاراکتره.

## مدیریت خطا

- تمام خطاها در کنسول لاگ می‌شن.
- در صورت بروز خطا، یک پیام دوستانه‌ی فارسی به کاربر نمایش داده می‌شه.
- در صورت rate limit شدن توسط Claude API، درخواست حداکثر ۳ بار با فاصله‌ی زمانی
  افزایشی دوباره امتحان می‌شه.
