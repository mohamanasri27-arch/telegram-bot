# Telegram FA↔EN Translator Bot

این بات تلگرام هر پیام فارسی را به انگلیسی و هر پیام انگلیسی را به فارسی ترجمه می‌کند.

## راه‌اندازی

1. یک بات از [@BotFather](https://t.me/BotFather) بسازید و توکن آن را بگیرید.
2. وابستگی‌ها را نصب کنید:
   ```
   pip install -r requirements.txt
   ```
3. متغیر محیطی توکن را تنظیم کنید (نمونه در `.env.example`):
   ```
   export TELEGRAM_BOT_TOKEN=your-token-here
   ```
4. بات را اجرا کنید:
   ```
   python bot.py
   ```
