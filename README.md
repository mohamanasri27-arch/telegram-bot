# Telegram FA↔EN Technical Translator Bot

بات تلگرامی که پیام‌ها رو بین فارسی و انگلیسی ترجمه می‌کنه، مخصوص متن‌های فنی برنامه‌نویسی
و پرامپت‌هایی که برای مدل‌های هوش مصنوعی نوشته می‌شن. ترجمه با Google Translate رایگان
(بدون نیاز به اکانت یا API key) انجام می‌شه و بلاک‌های کد، کد inline و اصطلاحات تکنیکال
قبل از ترجمه جدا شده و عیناً بازگردونده می‌شن تا دست‌نخورده بمونن.

## ساختار پروژه

- `bot.py` — نقطه ورود و هندلرهای تلگرام
- `translator.py` — منطق ترجمه (مستقل از لایه‌ی تلگرام)
- `requirements.txt` — وابستگی‌ها
- `.env.example` — نمونه‌ی متغیرهای محیطی
- `.gitignore`

## پیش‌نیازها

- Python 3.10 یا بالاتر
- یک توکن بات تلگرام از [@BotFather](https://t.me/BotFather)

هیچ کلید API یا اکانت اضافه‌ای لازم نیست.

## نصب و اجرا روی ویندوز

۱. مخزن رو کلون کنید و وارد پوشه‌ی پروژه بشید (در PowerShell یا CMD):

```powershell
git clone <repository-url>
cd telegram-bot
```

۲. یک محیط مجازی بسازید و فعالش کنید:

```powershell
python -m venv venv
venv\Scripts\activate
```

۳. وابستگی‌ها رو نصب کنید:

```powershell
pip install -r requirements.txt
```

۴. فایل `.env.example` رو کپی کنید و به `.env` تغییر نام بدید:

```powershell
copy .env.example .env
```

۵. فایل `.env` رو با یک ویرایشگر متن باز کنید و توکن واقعی بات رو جایگزین کنید:

```
TELEGRAM_BOT_TOKEN=توکن_بات_تلگرام_شما
```

۶. بات رو اجرا کنید:

```powershell
python bot.py
```

اگر همه‌چیز درست باشه، پیام `Bot started` توی خروجی نمایش داده می‌شه و بات آماده‌ی
دریافت پیامه. حالا می‌تونید توی تلگرام برید سراغ بات خودتون و باهاش چت کنید.

### توقف بات

برای متوقف کردن بات، در ترمینال کلیدهای `Ctrl + C` رو بزنید.

## دستورات بات

- `/start` — نمایش پیام خوش‌آمد و توضیح کوتاه نحوه‌ی استفاده
- `/help` — نمایش راهنمای کامل استفاده

## نحوه‌ی کار

- زبان پیام ورودی به‌صورت خودکار تشخیص داده می‌شه (فارسی یا انگلیسی).
- پیام فارسی به انگلیسی و پیام انگلیسی به فارسی ترجمه می‌شه.
- بلاک‌های کد (بین ` ``` `) و کد inline (بین `` ` ``) قبل از ترجمه جدا و بعد از ترجمه
  عیناً جایگزین می‌شن، پس دست‌نخورده می‌مونن.
- حداکثر طول پیام پشتیبانی‌شده ۴۰۰۰ کاراکتره.

## مدیریت خطا

- تمام خطاها در کنسول لاگ می‌شن.
- در صورت بروز خطا، یک پیام دوستانه‌ی فارسی به کاربر نمایش داده می‌شه.
- در صورت شکست موقت درخواست، حداکثر ۳ بار با فاصله‌ی زمانی افزایشی دوباره امتحان می‌شه.

## محدودیت‌های کیفیت ترجمه

چون این نسخه از Google Translate عمومی استفاده می‌کنه (نه یک مدل زبانی مثل Claude یا
Gemini)، ممکنه اصطلاحات تکنیکال رایج (مثل API، endpoint، prompt) رو به معادل فارسی
ترجمه کنه، نه اینکه به شکل انگلیسی نگه داره. اگر بعداً به یک کلید API از Claude یا
Gemini دسترسی پیدا کردید، می‌تونیم `translator.py` رو برای کیفیت ترجمه‌ی تخصصی‌تر و
حفظ اصطلاحات فنی، به یکی از اون سرویس‌ها سوییچ کنیم.
